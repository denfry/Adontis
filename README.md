# Adontis

Adontis is a Minecraft modpack developed by denfry.

Download and install it from CurseForge:
https://www.curseforge.com/minecraft/modpacks/adontis

## Installation

The pack is distributed through CurseForge. Install it with the CurseForge app or a launcher that supports CurseForge modpacks: open the link above, choose the version you want and install it. The mod list, Minecraft version and mod loader are shown on the CurseForge page.

## Reporting issues

Found a bug or a crash? Open an issue using the [bug report form](https://github.com/denfry/Adontis/issues/new/choose). Please include:

- the pack version you are running;
- steps to reproduce the problem;
- whether you use Iris shaders;
- whether you are playing on a server;
- relevant log output or the crash report.

## Repository

This repository holds the project's issue tracker and issue template. The pack itself is published on CurseForge.
